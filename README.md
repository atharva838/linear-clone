# Linear – Project Management Workspace

A modern, Linear-inspired project management application built using **HTML5, CSS3, and Vanilla JavaScript**. This project recreates the clean interface and productivity-focused workflows of modern issue-tracking platforms, with interactive features and responsive design.

## ✨ Features

- **Issue Management:** Create, edit, track, and delete issues.
- **Kanban Board:** Drag and drop issues between different workflow stages.
- **Issue Tracking:** Manage status, priority, assignees, and projects.
- **Project Management:** View project progress and completion statistics.
- **Command Palette:** Quickly navigate and execute actions using keyboard shortcuts.
- **Search & Filters:** Find issues and filter by status or priority.
- **Sorting:** Organize issues by creation date, priority, or title.
- **Issue Details:** Edit descriptions and properties through a dedicated detail panel.
- **CSV Export:** Export workspace issue data.
- **Dark & Light Mode:** Switch between themes.
- **Local Storage:** Preserve workspace data across browser refreshes.
- **Responsive UI:** Optimized for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling, responsive layout, animations |
| JavaScript (ES6+) | Application logic and interactions |
| DOM Manipulation | Dynamic rendering and UI updates |
| LocalStorage | Client-side data persistence |
| HTML Drag and Drop API | Kanban board interactions |

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `C` | Create a new issue |
| `Ctrl + K` / `Cmd + K` | Open command palette |
| `Esc` | Close active panel or modal |
| `Ctrl + Enter` / `Cmd + Enter` | Submit new issue |

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/atharva838/linear-clone.git
   ```

2. Open the project folder:

   ```bash
   cd linear-clone
   ```

3. Open `index.html` in your browser or use the VS Code Live Server extension.

No framework, dependencies, or build tools are required.

## ⚠️ Data & Architecture

This is a frontend-only implementation. Application data is stored in the browser using LocalStorage.

- Data persists across refreshes on the same browser.
- Data is not shared between different users or devices.
- Authentication, backend APIs, and real-time collaboration are not included.
